续费操作上有两件事要知道：

1. **付款默认不自动扣款**。到期前 14 天系统自动生成续费账单并发邮件，你也可以在客户区提前点「Generate Renewal Invoice」按原价生成账单；想省事可以在客户区开启 Auto-Recharge 自动续费，默认关闭。

## 退款政策和隐藏限制：下单前必须知道的几件事

这是全文最重要的一节。RackNerd 官方条款写得很直白：付款后默认不退款，退款按个案酌情处理，没有 30 天无理由退款。违规终止服务后发起拒付（chargeback），会被收取 $125–250 的行政费。

- **怕麻烦的新手**。没有退款兜底 + 无管理服务，第一次买 VPS 的话，有退款保障的商家容错率更高
